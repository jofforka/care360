# Care360 Plus Landing Page

A responsive, Apple-inspired GitHub Pages landing page for Care360 Plus.

## Quick setup

1. Open `script.js`.
2. Update the `CARE360_CONFIG` values:
   - Google Play URL
   - HMS website URL
   - APK filename and version
   - Contact details
   - Patient App launch date
3. Place the APK file inside the `downloads` folder.
4. Upload the project to a GitHub repository.
5. In GitHub, open **Settings → Pages** and publish from the main branch root.

## Files

- `index.html` — page structure and content
- `style.css` — responsive design and animations
- `script.js` — configuration, countdown and interactions
- `downloads/` — APK storage folder

No build process or framework is required.
